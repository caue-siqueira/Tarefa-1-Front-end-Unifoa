# Lista de Tarefas (To-Do List)

Projeto desenvolvido como atividade acadêmica da faculdade **UniFOA**, utilizando HTML, CSS e JavaScript.

## Sobre o projeto

A aplicação consiste em uma lista de tarefas simples, permitindo ao usuário organizar suas atividades.

### Funcionalidades

- **Adicionar tarefa:** permite inserir uma nova tarefa na lista.
- **Finalizar tarefa:** marca uma tarefa como concluída.
- **Desfazer conclusão:** permite retornar uma tarefa ao estado pendente.
- **Remover tarefa:** exclui uma tarefa da lista.
- **Contador:** exibe a quantidade de tarefas pendentes.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.

Não é necessário instalar dependências.

## Objetivo acadêmico

A atividade tem como objetivo praticar conceitos básicos de desenvolvimento front-end, incluindo estruturação HTML, estilização CSS, manipulação do DOM e eventos com JavaScript.

**Instituição:** Centro Universitário de Volta Redonda (UniFOA).
